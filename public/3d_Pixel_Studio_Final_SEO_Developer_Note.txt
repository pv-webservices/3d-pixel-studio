- Use “Insights” everywhere instead of “Blog”.

8. CANONICAL SETTINGS
---------------------
Every important page should have a self-referencing canonical.

Home → /
Work → /work/
Studio → /studio/
Services → /services/
Insights → /insights/
Article → its own article URL
Project → its own project URL

Also make sure only one final domain version is used consistently:
- HTTPS only
- Preferred www/non-www version only
- Redirect all duplicate versions to the preferred canonical URL

11. IMAGE SEO
-------------
For meaningful CGI images:

Use descriptive filenames.

Good:
shubh-kamna-heights-exterior-cgi.webp

Bad:
IMG_0382-final2.webp

Use useful ALT text.

Good:
Shubh Kamna Heights residential tower exterior CGI at dusk.

Bad:
best 3d architectural visualization cgi rendering mumbai india

Also:
- Use WebP/AVIF where suitable
- Set width/height
- Use responsive srcset/sizes
- Lazy-load below-the-fold images
- Do not lazy-load the main hero/LCP image
- Important portfolio images should use proper <img> or <picture> elements rather than only CSS backgrounds
